# Mehrsprachigkeit (i18n)

Gleiches Muster wie ELO (`@app-galaxy/translate-ui`): Sprachen **de** (Basis), **fr**, **it**, **en**.

## Ablage

```
apps/app/public/assets/locales/<lang>/<section>.locale.json
```

| Sektion | Inhalt | Geladen |
|---|---|---|
| `common` | App-Titel, Menü (`menu.*` = Sitemap), Shell (`shell.*`), Aktionen (`common.*`), Ampel-Status (`status_range.*`), Fehler | beim Start (`initialLocalesFiles`) |
| `forms` | Feldbezeichnungen, Validierungstexte | beim Start |
| `home` | Einstiegsseite | Route `/` (`data.path: 'home'`) |
| `ranges` | Übersicht Schiessplätze + Detailseiten | Route `/schiessplaetze` |
| `admin` | Datenverwaltung (folgt) | Route `/admin` |

Verschachtelte Schlüssel, `snake_case`: `ranges.columns.quota_info`. Platzhalter mit
`{{n}}` → `'count' | translate: { n: 8 }`.

## Verwendung

```ts
// Template
{{ 'menu.ranges' | translate }}
{{ 'foot_count' | translate: { n: 8, total: 8 } }}

// Klasse
private readonly translate = inject(TranslateService);
this.translate.translate('common.save');
this.translate.lang = 'fr';          // wechselt und speichert (localStorage app.lang)
```

Routen laden ihre Sektion über den Resolver:

```ts
{ path: 'schiessplaetze', data: { path: 'ranges' }, resolve: LocaleResolver.default, … }
```

Konfiguration in `apps/app/src/app/app.config.ts` (`provideTranslate`), Sprachliste aus
`@slim/shared` (`APP_LANGUAGES`). Sprachwahl in der Kopfzeile:
`apps/app/src/app/common/language-switch.component.ts`.

## Übersetzen

`de` ist die Quelle. Die anderen Sprachen werden mit Transmart (OpenAI) erzeugt und
anschliessend fachlich geprüft:

```bash
# OPEN_API_KEY in .env
npm run translate          # npx transmart (transmart.config.js)
npm run translate:tool     # tools/transmart.js mit Fortschrittsausgabe
```

Der Cache `apps/app/public/assets/locales/.cache/` ist git-ignoriert.

## Regeln

- Keine Texte im Template hart codieren (ausser Entwicklungsseiten wie `/styleguide`).
- Schlüssel nach Sektion gruppieren, Menü-Schlüssel entsprechen der Sitemap.
- Neue Sektion = neue Datei in allen vier Sprachen + Resolver an der Route.
- Schweizer Schreibweise («ss», keine «ß»).
